# Симулятор муравья (Ant Simulator)

Учебная игра на C# / WPF: муравей ходит по полю из чёрных и белых клеток,
перекрашивает их и поворачивает по правилам, которые составляет пользователь.
Обобщение классического «муравья Лэнгтона».

## Возможности
- Поле произвольного размера (5–600 клеток по каждой оси), пустое или случайное.
- Ручное редактирование поля: ЛКМ — перекрасить клетку, ПКМ — поставить муравья.
- Конструктор правил отдельно для БЕЛОЙ и для ЧЁРНОЙ клетки:
  «Повернуть налево», «Повернуть направо», «Идти прямо», «Перекрасить клетку».
  Количество и порядок блоков произвольные (кнопки «Добавить», «Удалить», «Выше», «Ниже»).
- Управление: «Сгенерировать», «Запустить», «Пауза», одиночный «Шаг».
- Регулировка скорости (1–500 шагов за кадр), счётчик шагов и чёрных клеток.

## Семантика шага
1. Определяется цвет клетки под муравьём.
2. Все блоки правила для этого цвета выполняются сверху вниз:
   повороты меняют направление, «Перекрасить» инвертирует цвет текущей клетки,
   «Идти прямо» сдвигает муравья на одну клетку.
3. Счётчик шагов увеличивается на 1.

Поле замкнуто в тор: за правым краем следует левый, за верхним — нижний.
Муравей отображается красной клеткой.

Правила по умолчанию (муравей Лэнгтона):
- белая: направо → перекрасить → вперёд;
- чёрная: налево → перекрасить → вперёд.
Примерно после 10 000 шагов возникает регулярное «шоссе».

## Требования
- Windows 10/11, .NET 8 SDK (для сборки) или .NET 8 Desktop Runtime.
- Готовая сборка из Releases самодостаточна и не требует установленного .NET.
